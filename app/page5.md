## 🤝 Contributing Guide

We welcome contributions from developers, architects, and enthusiasts who want to improve the AVIS Datalake Engine. To keep collaboration smooth, follow these steps:

### 🔧 How to Contribute
- **Fork the Repository**: Create your own copy to experiment safely.  
- **Create a Branch**: Use descriptive names like `feature/pagination-fix` or `docs/add-schema-guide`.  
- **Commit Changes**: Write clear commit messages that explain *why* the change was made.  
- **Open a Pull Request (PR)**: Submit your branch for review. Include screenshots or code snippets if relevant.  
- **Review & Merge**: Collaborators will review your PR. Once approved, it will be merged into the main branch.  

---

### 📜 Contribution Standards
- **Code Style**: Follow PHP 8.2+ standards and PSR‑12 formatting.  
- **Documentation**: Update README files when adding new features.  
- **Testing**: Validate changes with sample JSON payloads before submitting.  
- **Security**: Never commit sensitive credentials or private data.
