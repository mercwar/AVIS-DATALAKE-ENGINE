# 📘 AVIS Public Tutorial — Page 4  
## 🩺 Diagnostics & Environment Verification

The AVIS Datalake Engine includes built‑in diagnostic tools to validate directory structures, tenant readiness, and router/switch connectivity. Public users can run these checks to ensure their environment is stable before uploading or browsing payloads.

---

## 🔧 Diagnostic Uplink Script
The `diagnostic_uplink.php` script verifies engine status and tenant directories:

```php
<?php
/* AVIS-DIAGNOSTIC: diagnostic_uplink.php */
header('Content-Type: text/plain');
echo "=== AVIS DATALAKE ENGINE DIAGNOSTIC UPLINK STATUS ===\n\n";

include_once("UniversalRoot.php");

echo "Config Validation:\n";
echo "├─ Engine Core Status: " . (isset($avis_ini['SESSION_ON']) ? "ONLINE" : "OFFLINE") . "\n";
echo "├─ Scan Target Path:  " . ($user_dir ?? 'ERROR: NOT DEFINED') . "\n";
echo "└─ Subfolder Route:   " . ($user_loc ?? 'ERROR: NOT DEFINED') . "\n\n";

echo "Storage Node Discovery:\n";
if (is_dir($user_dir)) {
    echo "└─ [SUCCESS] Tenant folder space successfully mapped.\n";
    $profiles = glob($user_dir . '*', GLOB_ONLYDIR);
    echo "   └─ Active Profiles Loaded: " . count($profiles) . " users registered.\n";
} else {
    echo "└─ [CRITICAL ERROR] Target path not found. Verify your environment directory structure.\n";
}
```

---

## 📊 What the Diagnostic Checks
- **Engine Core Status** → Confirms whether the session is active.  
- **Scan Target Path** → Displays the root directory being scanned.  
- **Subfolder Route** → Shows the `$user_loc` path for JSON payloads.  
- **Tenant Discovery** → Counts active user profiles.  

---

## 🛡️ Error Handling
- **Missing Path** → Engine reports `CRITICAL ERROR: Target path not found`.  
- **Empty Tenant Folder** → Displays “NO FILE AVAILABLE” cards in the public browser.  
- **Corrupted JSON** → Skipped gracefully, preventing crashes.  

---

## ✅ Best Practices for Public Users
- Run diagnostics before uploading payloads.  
- Confirm `$user_dir` and `$user_loc` are correctly defined.  
- Use `clearstatcache()` before sorting directories to avoid stale timestamps.  
- Expect “NO FILE AVAILABLE” warnings for new users without JSON payloads.
